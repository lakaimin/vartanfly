Python 互動探索之旅

寫程式，就像賦予電腦超能力

Python 是世界上最受歡迎的程式語言之一。它簡潔、易讀，就像在用英文下指令一樣。不管是人工智慧、網站開發還是數據分析，Python 都能輕鬆搞定。

儲存資料

使用「變數」來記住名字、分數或狀態。

做出決策

使用「條件判斷」讓程式在不同情況下有不同反應。

自動重複

使用「迴圈」讓電腦幫你做無聊的重複性工作。

變數 (Variables)

變數就像是一個有名字的盒子，你可以把資料（文字、數字、顏色）放進去。試著點擊程式碼中的顏色，然後按執行！

variables.py

# 建立一個變數來儲存能量球的顏色

orb_color = "紅色"


# 將能量球啟動，並套用剛剛設定的顏色

activate_orb(orb_color)

條件判斷 (Conditionals)

條件判斷 `if...else` 就像是程式的十字路口。根據條件是否成立，程式會決定走哪一條路。點擊天氣變數來改變情境！

conditionals.py

# 設定目前的天氣狀況

weather = "下雨"


if weather == "下雨":

# 如果是下雨天

take_action("撐傘 ☔")

else:

# 否則 (晴天)

take_action("戴墨鏡 😎")

loops.py
